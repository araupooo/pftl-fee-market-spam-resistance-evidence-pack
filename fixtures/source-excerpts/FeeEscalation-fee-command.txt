282: ### `fee` command
283: 
284: **The `fee` RPC and WebSocket command is still experimental, and may
285: change without warning.**
286: 
287: `fee` takes no parameters, and returns information about the current local
288: [fee escalation](#fee-escalation) and [transaction queue](#transaction-queue)
289: state as both fee levels and drops. The drop values assume a
290: single-singed reference transaction. It is up to the user to compute the
291: necessary fees for other types of transactions. (E.g. multiply all drop
292: values by 5 for a multi-signed transaction with 4 signatures.)
293: 
294: The `fee` result is always instantanteous, and relates to the open
295: ledger. It includes the sequence number of the current open ledger,
296: but may not make sense if rippled is not synced to the network.
297: 
298: Result format:
299: 
300: ```
301: {
302:    "result" : {
303:       "current_ledger_size" : "16", // number of transactions in the open ledger
304:       "current_queue_size" : "2", // number of transactions waiting in the queue
305:       "expected_ledger_size" : "15", // one less than the number of transactions that can get into the open ledger for the base fee.
306:       "max_queue_size" : "300", // number of transactions allowed into the queue
307:       "ledger_current_index" : 123456789, // sequence number of the current open ledger
308:       "levels" : {
309:          "reference_level" : "256", // level of a reference transaction. Always 256.
310:          "minimum_level" : "256", // minimum fee level to get into the queue. If >256, indicates the queue is full.
311:          "median_level" : "281600", // lastLedgerMedianFeeLevel used in escalation calculations.
312:          "open_ledger_level" : "320398" // minimum fee level to get into the open ledger immediately.
313:       },
314:       "drops" : {
315:          "base_fee" : "10", // base fee of a reference transaction in drops.
316:          "minimum_fee" : "10", // minimum drops to get a reference transaction into the queue. If >base_fee, indicates the queue is full.
317:          "median_fee" : "11000", // drop equivalent of "median_level" for a reference transaction.
318:          "open_ledger_fee" : "12516" // minimum drops to get a reference transaction into the open ledger immediately.
319:       }
320:    }
321: }
322: ```
