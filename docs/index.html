Live testnet observations (network 2025, postfiatd 1.0.9) plus a model computed from the pinned protocol revision (0085a1ff885d6a446369cf73a4430f75af22be55, tag v1.0.9). Probe window: 2026-11-22 18:47–19:00 UTC. Assessment only: no transactions were sent and no flood traffic was generated — see methodology for the safety boundary.

Verdict

Not yet proven — sound on paper, untested in practice. The pinned code implements a coherent, layered defence, and every parameter is at its documented default on the testnet. But the testnet is idle, so no part of the defence has ever been observed working under load. Full reasoning: decision memo.
